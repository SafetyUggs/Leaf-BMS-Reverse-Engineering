XML contains all tables within 3NA0D firmware. Use ECUFLASH to edit. Checksums must be corrected before flashing a modified firmware. Capacity changes are not part of this XML, there are ~86 constants that need modifying at the ASM level, as well as coulomb counter functions and integrators that need scaling to prevent overflow of AH*S variables. If Scaled, any functions that use or report the scaled variables must also be modified.
